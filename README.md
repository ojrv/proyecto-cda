# 🎛️ Dashboard Institucional – Iglesia Casa del Alfarero

Sistema web modular para la gestión del Grupo de Alabanza y Adoración. Conectado a Supabase, visualmente coherente y escalable para futuras ampliaciones.

![Deploy](https://img.shields.io/badge/deploy-GitHub%20Pages-green)

## 📦 Estructura del Proyecto

- `index.html`: Dashboard principal con navegación modular.
- `css/`: Estilos institucionales definidos por paleta y tipografía coherente.
- `js/`: Scripts organizados por función, con conexión validada a Supabase.
- `supabase/`: Configuración de claves y endpoints para conexión segura.

## 🚀 Funcionalidades

- Login por alias único, validado en Supabase.
- Visualización dinámica de usuarios y roles.
- Formularios institucionales con estilos coherentes.
- Navegación modular entre secciones del dashboard.
- Inserción y lectura de datos en tiempo real.

## 🧠 Tecnologías Utilizadas

- HTML5 + CSS3
- JavaScript
- Supabase
- GitHub Pages
